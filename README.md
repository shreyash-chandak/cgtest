# CG Assignment - 3

## Prerequisites (Ubuntu/Debian)
Install the required toolchain and OpenGL libraries:

```bash
sudo apt update
sudo apt install build-essential libgl1-mesa-dev libglew-dev libglfw3-dev libglm-dev
```

## Build
From the project root:

```bash
make
```

This builds the executable named `scene`.

## Run

```bash
./scene
```

## Clean build artifacts

```bash
make clean
```
